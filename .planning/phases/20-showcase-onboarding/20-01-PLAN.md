# Plano 20-01 — Showcase do Sistema

## Objetivo
Criar uma tela de apresentação visual do sistema (`app/showcase.tsx`) que aparece entre o WelcomeScreen e o Login quando o usuário clica em "ACESSAR SISTEMA". Deve ter identidade visual diferente do onboarding (que é tutorial), sendo mais próxima de uma "landing page" nativa — densa, impactante, scrollável, sem paginação.

## Diferença para o Onboarding
| Onboarding (Conhecer o App) | Showcase (nova tela) |
|---|---|
| Tutorial passo a passo | Apresentação do produto |
| Slides com swipe | Scroll vertical único |
| Explica como usar | Mostra o que o sistema entrega |
| Tom: instrutivo | Tom: institucional / confiança |
| Navegação com dots | Sem paginação, leitura livre |

## Novo Fluxo
```
WelcomeScreen (index.tsx)
  └── "ACESSAR SISTEMA" → showcase.tsx → /(auth)/login
  └── "Conhecer o App"  → onboarding.tsx (inalterado neste plano)
  └── "Validar Token"   → /(auth)/register
```

## Estrutura da Tela Showcase

### Seção 1 — Hero
- Logo + nome "TCS" centralizado
- Tagline: "Sistema Oficial de Vistoria Técnica — Defesa Civil"
- Barra de risco R1→R4 decorativa (igual ao WelcomeScreen, mas maior)

### Seção 2 — Stats decorativos (3 números)
Cards horizontais com números de impacto:
- "10 Elementos" — Formulário técnico completo
- "R1 → R4"     — Classificação de risco precisa
- "100% Offline" — Funciona sem conexão

### Seção 3 — Funcionalidades (6 cards em grid 2×3)
Cada card: ícone colorido + título + descrição curta
1. Vistoria em Campo — `clipboard` #F59E0B — Registro georreferenciado com fotos e formulários dinâmicos
2. Laudo PDF Técnico — `file-text` #8B5CF6 — Relatório completo gerado instantaneamente ao fim da vistoria
3. Mapa & GPS — `map-pin` #3B82F6 — Localização precisa de cada edificação inspecionada
4. Funciona Offline — `wifi-off` #10B981 — Dados salvos localmente e sincronizados ao reconectar
5. Gestão de Equipes — `users` #06B6D4 — Supervisores, agentes e grupos organizados por município
6. Auditoria & Logs — `shield` #EF4444 — Rastreabilidade completa de todas as ações no sistema

### Seção 4 — CTA final
- Botão primário: "Entrar no Sistema" → `router.replace('/(auth)/login')`
- Link secundário discreto: "← Voltar" → `router.back()`

## Animações
- `FadeIn` + `slideUp` na entrada de cada seção via `Animated.stagger`
- Sem animações de loop (diferente do WelcomeScreen)
