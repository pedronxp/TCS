# 19-03 — NavBar mapa + Laudo visual + Mensagens Resultado

## Objetivo

1. NavBar some automaticamente ao abrir o mapa (não sobrepõe controles inferiores)
2. Tela "Resultado Final" (resultado.tsx) reformulada visualmente — não parece JSON
3. Mensagens/ações em resultado.tsx funcionando (Gerar Termo de Interdição + outros)

---

## Fix 1 — NavBar desaparece na tela de mapa

### Diagnóstico

`components/BottomNavBar.tsx` tem `NAVBAR_VISIBLE_PATHS` que inclui `/mapas`. O navbar usa `position: absolute, bottom: 0` com `elevation: 12`, sobrepondo os controles do mapa nativo (zoom, localização, etc.).

### Solução

Remover `/mapas` de `NAVBAR_VISIBLE_PATHS`. O navbar não aparece na tela de mapa.

```ts
// Antes:
const NAVBAR_VISIBLE_PATHS = ['/dashboard', '/inspecoes', '/mapas', '/perfil', '/modulos'];

// Depois:
const NAVBAR_VISIBLE_PATHS = ['/dashboard', '/inspecoes', '/perfil', '/modulos'];
```

### Arquivos
- `components/BottomNavBar.tsx` — remover `/mapas` de NAVBAR_VISIBLE_PATHS

## Fix 3 — Mensagens Gerar Termo não aparecem

### Diagnóstico

`gerarTermoInterdicao()` em resultado.tsx:
- Linha 323: `setShowTermoModal(false)` é chamado imediatamente ao confirmar
- O modal fecha, depois tenta gerar o PDF — este fluxo é correto
- O problema pode ser que o `Alert.alert` de validação (linha 319) está sendo chamado quando o modal ainda está aberto, e algumas versões do Android não mostram Alert quando há um Modal RN por cima

**Fix:** Atrasar `setShowTermoModal(false)` para depois da validação:
```ts
const gerarTermoInterdicao = async () => {
  if (!termoForm.nomeNotificado.trim()) {
    Alert.alert('Campo obrigatório', 'Preencha o nome do notificado.');
    return; // modal permanece aberto
  }
  setShowTermoModal(false); // fechar DEPOIS da validação
  // ...
```

Também verificar que o botão "Gerar Termo" no modal não está em estado `disabled` inadvertidamente.

### Arquivos
- `app/(panel)/inspecoes/resultado.tsx` — reordenar setShowTermoModal + verificar estado do botão
