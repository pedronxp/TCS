# 19-05 — Módulo de Grupo + Municípios melhorados

## Objetivo

1. Criar o **Módulo de Grupo** — tela para gerenciar grupos de agentes por área/turno/zona
2. Melhorar o módulo de **Municípios** no painel master_admin

---

## Feature 1 — Módulo de Grupo

### O que é

Grupos permitem ao admin/supervisor organizar agentes em equipes (ex: "Equipe Norte", "Plantão A", "Zona Sul"). Um agendamento ou relatório pode ser filtrado por grupo.

### Escopo mínimo (MVP)

1. **Tabela local no SQLite** — `grupos` (id, nome, municipio, criado_em) e `grupo_membros` (grupo_id, agente_uid, agente_nome)
2. **Tela de grupos** — lista de grupos do município com contagem de membros
3. **Criar/editar grupo** — nome do grupo
4. **Adicionar/remover membros** — seletor de agentes aprovados do município
5. **Sem Supabase** nesta fase — grupos ficam locais (podem ser sincronizados em fase futura)

### Rota

`app/(panel)/grupos/index.tsx` — acessível pelo menu admin/supervisor

### Arquivos a criar
- `app/(panel)/grupos/index.tsx` — lista de grupos
- `app/(panel)/grupos/[id].tsx` — detalhe do grupo (membros + ações)

### Arquivos a modificar
- `utils/database.ts` — migration v8: tabelas `grupos` e `grupo_membros`
- `app/(panel)/admin/index.tsx` — adicionar card "Grupos" no menu admin
- `app/(panel)/supervisor/index.tsx` — adicionar acesso a grupos

## Feature 2 — Módulo de Municípios melhorado

### Diagnóstico

O módulo atual de municípios no painel master_admin (`app/(panel)/master/municipios.tsx`) provavelmente lista municípios de forma básica.

### Melhorias

1. **Barra de busca** — filtrar município por nome
2. **Card de município** com:
   - Nome
   - Total de vistorias
   - Total de agentes ativos
   - Último acesso (data da última vistoria)
   - Badge de risco predominante (cor do nível mais frequente)
3. **Ação de navegação** — tocar no card abre detalhes do município (vistorias recentes, agentes, KPIs)
4. **Adicionar município** — botão + no header, modal com input de nome
5. **Ordenação** — por vistorias (desc) por padrão, toggle por nome alfabético

### Arquivos a modificar
- `app/(panel)/master/municipios.tsx` — redesenho completo da tela
