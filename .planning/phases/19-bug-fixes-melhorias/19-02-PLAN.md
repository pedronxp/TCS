# 19-02 — Agendamento para master_admin + bug data/hora

## Objetivo

1. Permitir que `master_admin` crie agendamentos (atualmente não funciona — `carregarAgentes` filtra por `profile.municipio` que é nulo/`'*'` para master_admin)
2. Corrigir o campo de data/hora — input de texto manual com máscara DD/MM/AAAA HH:MM não tem formatação automática e é confuso

---

## Bug 1 — master_admin não consegue criar agendamento

### Diagnóstico

`app/(panel)/agendamentos/index.tsx` → `carregarAgentes()`:

```ts
const { data } = await supabase
  .from('users')
  .select('uid, name')
  .eq('role', 'agent')
  .eq('municipio', profile.municipio)  // ← PROBLEMA: master_admin tem municipio '*' ou null
  .eq('isApproved', true);
```

Para `master_admin`, `profile.municipio` pode ser `'*'` ou `null`, então o filtro retorna 0 agentes.

Além disso, ao criar um agendamento, o campo `municipio` é preenchido com `profile.municipio` (`'*'`), que é inválido.

### Solução

1. Para `master_admin`, ao carregar agentes: remover filtro de município e buscar todos os agentes aprovados.
2. Adicionar seletor de município para master_admin no modal de criação do agendamento — o master escolhe primeiro o município, depois filtra os agentes daquele município.

```ts
// carregarAgentes — master_admin busca todos
const query = supabase.from('users').select('uid, name, municipio').eq('role', 'agent').eq('isApproved', true);
if (profile.role !== 'master_admin') {
  query = query.eq('municipio', profile.municipio);
}
```

3. No save do agendamento para master_admin, usar `agenteSelecionado.municipio` como município do agendamento.

## Bug 2 — Campo data/hora confuso e bugado

### Diagnóstico

O campo de data usa `TextInput` com máscara manual `DD/MM/AAAA HH:MM`. A função `parseDateInput()` rejeita qualquer formato que não seja exato. O usuário não recebe feedback em tempo real enquanto digita.

### Solução

Substituir o `TextInput` de data/hora por dois campos separados com máscara automática ao digitar:
- Campo 1: Data `DD/MM/AAAA` — máscara inserindo `/` automaticamente
- Campo 2: Hora `HH:MM` — máscara inserindo `:` automaticamente

Cada campo mostra um placeholder claro. Validação em tempo real com feedback de erro inline.

```ts
// Máscara de data automática
const handleDataChange = (text: string) => {
  const nums = text.replace(/\D/g, '').slice(0, 8);
  let formatted = nums;
  if (nums.length > 4) formatted = `${nums.slice(0, 2)}/${nums.slice(2, 4)}/${nums.slice(4)}`;
  else if (nums.length > 2) formatted = `${nums.slice(0, 2)}/${nums.slice(2)}`;
  setDataInput(formatted);
};

// Máscara de hora automática
const handleHoraChange = (text: string) => {
  const nums = text.replace(/\D/g, '').slice(0, 4);
  let formatted = nums;
  if (nums.length > 2) formatted = `${nums.slice(0, 2)}:${nums.slice(2)}`;
  setHoraInput(formatted);
};
```

Montar ISO string: `parseDateInput(dataInput + ' ' + horaInput)`.

### Arquivos
- `app/(panel)/agendamentos/index.tsx` — substituir campo data, adicionar campo hora, ajustar parseDateInput
