## Fix 2 — Dashboard master: "Severidade Global" + "Eventos Recentes"

### Diagnóstico

`app/(panel)/master/index.tsx`:

**"Severidade Global"** (linhas 161–186): É uma barra de risco que mostra proporção Alto vs Moderado/Baixo com apenas 2 categorias. O usuário não entendeu o que significa.

**Problema:** A barra só distingue "Alto" de "Moderado/Baixo" sem separar R1/R2/R3/R4. Além disso, o título "Severidade Global" é confuso.

**Fix:**
- Renomear para "Distribuição de Risco"
- Mostrar 4 segmentos coloridos (R1 verde, R2 amarelo, R3 laranja, R4 vermelho) se o RPC `get_dashboard_kpis_master` retornar esses dados
- Se o RPC não tiver dados por R1-R4, usar a barra atual mas com legenda mais clara: "R3/R4 = Alto Risco" e "R1/R2 = Risco Controlado"

**"Eventos Recentes do Sistema"** (linhas 208–228): Mostra logs do `system_logs` do Supabase. O usuário questionou a necessidade no dashboard do master.

**Fix:**
- O master_admin **deve** ver eventos recentes — é parte do controle global
- Mas melhorar: traduzir `acao` usando labels do AUDIT_ACTION_LABELS
- Adicionar ícone por tipo de ação (em vez de sempre `activity`)
- Limpar entradas de LOGIN que aparecem frequentemente (já tem filtro `.not('acao', 'eq', 'LOGIN')`)
- Renomear seção para "Atividade Recente"

### Arquivos
- `app/(panel)/master/index.tsx` — renomear "Severidade Global", melhorar seção de logs
