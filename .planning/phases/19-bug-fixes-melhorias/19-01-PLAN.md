# 19-01 — Foto wizard persistente + GPS logradouro

## Objetivo

Corrigir dois bugs de campo críticos:
1. Foto tirada no wizard some ao navegar de volta
2. GPS preenche campo "rua" com a palavra "Logradouro" (literal) e bairro errado

---

## Bug 1 — Foto some no wizard

### Diagnóstico

`wizard.tsx` → `tirarFoto()` usa `ImagePicker.launchCameraAsync()` que retorna um URI temporário `file://`.
Quando o sistema operacional abre a câmera (activity separada no Android), o processo React Native pode ser pausado ou o componente pode ser remontado, zerando o `respostas` state.
Além disso, URIs temporárias do `expo-image-picker` no Android são invalidadas após reinicialização de atividade.

### Solução

Copiar a foto para `FileSystem.documentDirectory` imediatamente após a captura, usando `expo-file-system`. Isso gera uma URI persistente que sobrevive ao ciclo de vida do app.

```ts
// Em tirarFoto():
import * as FileSystem from 'expo-file-system/legacy';

const fotoDir = FileSystem.documentDirectory + 'fotos/';
await FileSystem.makeDirectoryAsync(fotoDir, { intermediates: true });
const destino = fotoDir + `foto_${Date.now()}.jpg`;
await FileSystem.copyAsync({ from: result.assets[0].uri, to: destino });
setResposta(perguntaId, destino);
```

## Bug 2 — GPS "Logradouro" no campo de rua + bairro errado

### Diagnóstico

`dados-iniciais.tsx` → `reverseGeocode()` usa Nominatim OpenStreetMap.

**Problema rua:** `addr.road` em regiões brasileiras às vezes retorna a string literal `"Logradouro"` (tipo de via, não nome) quando o OSM não tem o nome cadastrado. Também pode retornar `"Rua"`, `"Avenida"` sem o nome completo.

**Problema bairro:** `city_district` e `district` no Nominatim BR frequentemente retornam subdivisões administrativas largas (ex: "Zona Norte") em vez do bairro real. O campo `suburb` costuma ser mais preciso para bairros brasileiros.

### Solução

1. **Rua:** Adicionar filtro para rejeitar valores genéricos:
```ts
const PALAVRAS_INVALIDAS_RUA = ['logradouro', 'rua', 'avenida', 'via', 'estrada', 'travessa'];
const ruaCandidata = addr.road || addr.pedestrian || addr.footway || addr.path || '';
const rua = PALAVRAS_INVALIDAS_RUA.includes(ruaCandidata.toLowerCase().trim()) ? '' : ruaCandidata;
```

2. **Bairro:** Reordenar prioridade — `suburb` primeiro (mais preciso no Brasil), depois `neighbourhood`, depois `city_district`:
```ts
const bairro =
  addr['suburb'] ||
  addr['neighbourhood'] ||
  addr['quarter'] ||
  addr['city_district'] ||
  addr['district'] ||
  addr['hamlet'] ||
  addr['village'] ||
  '';
```
