# Plan 07-02: Banner de Risco em Tempo Real no Wizard

**Phase:** 07 — Formulários + Classificação de Risco
**Wave:** 2 of 3
**Req IDs:** FORM-02
**Depends on:** 07-01 (estrutural_avancado agora tem limites[] corretos)
**Goal:** Exibir o nível de risco calculado (R1/R2/R3/R4) no footer do wizard durante o preenchimento, atualizado a cada resposta, visível apenas após pelo menos 1 resposta

## Context

O wizard já tem `calcularNivelRisco()` (linha 199–233) mas ela só é chamada em `finalizar()`. O FORM-02 exige exibição **durante** o preenchimento.

**Estrutura atual do footer (linha 498–517):**

```tsx
<View style={[styles.footer, { backgroundColor: theme.surfaceHighlight, borderTopColor: theme.border }]}>
  {step > 0 && (
    <TouchableOpacity style={[styles.cancelBtn, { borderColor: theme.border }]} onPress={() => setStep(s => s - 1)}>
      <Text style={[styles.cancelText, { color: theme.textSecondary }]}>VOLTAR</Text>
    </TouchableOpacity>
  )}
  <TouchableOpacity
    style={[styles.nextBtn, { backgroundColor: theme.primary, flex: step > 0 ? 2 : 1 }]}
    onPress={avancar}
    disabled={salvando}
  >
    ...
  </TouchableOpacity>
</View>
```

**O que adicionar:** Um banner acima dos botões (dentro do mesmo `<View style={styles.footer}>`) que só aparece quando `Object.keys(respostas).length > 0`.

**Imports já presentes no wizard:**
- `useTheme` — usa `theme.primary`, `theme.text`, etc.
- `Feather` de `@expo/vector-icons`
- `riscoLabel`, `riscoColor` devem ser importados de `utils/riscoUtils.ts` (não existem no wizard atualmente — adicionar import)

**Restrições:**
- Não usar `react-native-reanimated` — usar `Animated` do react-native (já importado via desestruturação no topo, mas `Animated` ainda não está importado — adicionar)
- Não duplicar `calcularNivelRisco()` — ela já existe no wizard, apenas chamar via `useMemo`
- Banner deve ser `width: '100%'`, acima dos botões, dentro do container `footer`

## Tasks

### Task 1: Adicionar imports necessários e `useMemo` de risco reativo

**File:** `app/(panel)/inspecoes/wizard.tsx`

**What:**

1. Adicionar `useMemo` ao import do React na linha 1:

```typescript
import React, { useEffect, useMemo, useRef, useState } from 'react';
```

2. Adicionar `Animated` ao import do react-native na linha 2–5:

```typescript
import {
  Animated, View, Text, StyleSheet, TouchableOpacity, ScrollView, TextInput,
  ActivityIndicator, Alert, KeyboardAvoidingView, Platform, Image
} from 'react-native';
```

3. Adicionar import de `riscoLabel` e `riscoColor` após os imports locais existentes (após linha 17):

```typescript
import { riscoLabel, riscoColor } from '../../../utils/riscoUtils';
```

4. Adicionar `useRef` para o valor animado logo após as declarações de estado existentes (após linha 66, antes de `useEffect`):

```typescript
const riscoAnim = useRef(new Animated.Value(0)).current;
```

5. Adicionar `useMemo` para calcular risco reativo logo após o `riscoAnim` ref:

```typescript
const riscoAtual = useMemo(() => {
  if (Object.keys(respostas).length === 0) return null;
  return calcularNivelRisco();
}, [respostas, perguntas, limites]);
```

6. Adicionar `useEffect` para animar entrada/saída do banner quando `riscoAtual` muda (logo após o `useMemo`):

```typescript
useEffect(() => {
  Animated.timing(riscoAnim, {
    toValue: riscoAtual ? 1 : 0,
    duration: 220,
    useNativeDriver: true,
  }).start();
}, [riscoAtual]);
```

**Why:** `useMemo` recalcula apenas quando `respostas`, `perguntas` ou `limites` mudam. A animação usa `useNativeDriver: true` com `opacity` — compatível sem reanimated. O resultado é `null` quando nenhuma resposta foi dada, evitando mostrar "R1" em formulário vazio.

**Atenção:** `calcularNivelRisco()` dentro do componente usa closures de `respostas`, `perguntas` e `limites` — o `useMemo` captura esses valores corretamente sem precisar repassar como parâmetros.

### Task 2: Adicionar banner de risco no footer

**File:** `app/(panel)/inspecoes/wizard.tsx`

**What:** Dentro do `<View style={[styles.footer, ...]}>` (linha 499), inserir o banner **antes** do botão VOLTAR e do botão PRÓXIMA/FINALIZAR:

```tsx
{/* Banner de risco em tempo real — aparece após primeira resposta */}
{riscoAtual && (
  <Animated.View
    style={[
      styles.riscoBanner,
      {
        backgroundColor: riscoColor(riscoAtual) + '1A', // 10% opacidade
        borderColor: riscoColor(riscoAtual),
        opacity: riscoAnim,
        transform: [{ translateY: riscoAnim.interpolate({ inputRange: [0, 1], outputRange: [8, 0] }) }],
      },
    ]}
  >
    <Feather name={riscoAtual === 'r4' || riscoAtual === 'r3' ? 'alert-triangle' : 'shield'} size={16} color={riscoColor(riscoAtual)} />
    <Text style={[styles.riscoBannerLabel, { color: riscoColor(riscoAtual) }]}>
      RISCO ATUAL
    </Text>
    <Text style={[styles.riscoBannerNivel, { color: riscoColor(riscoAtual) }]}>
      {riscoAtual.toUpperCase()} — {riscoLabel(riscoAtual)}
    </Text>
  </Animated.View>
)}
```

Adicionar os estilos no `StyleSheet.create` no final do arquivo (após `cancelText`):

```typescript
riscoBanner: {
  width: '100%',
  flexDirection: 'row',
  alignItems: 'center',
  gap: 8,
  paddingVertical: 10,
  paddingHorizontal: 14,
  borderRadius: 10,
  borderWidth: 1,
  marginBottom: 12,
},
riscoBannerLabel: {
  fontSize: 10,
  fontWeight: '800',
  letterSpacing: 1.2,
},
riscoBannerNivel: {
  fontSize: 13,
  fontWeight: '700',
  flex: 1,
  textAlign: 'right',
},
```

**Why:** O banner fica no footer (sempre visível) em vez de no scroll (poderia ser coberto pelo teclado). A cor de fundo usa 10% de opacidade (`+ '1A'` em hex) para não sobrecarregar visualmente. O `flex: 1` no texto do nível empurra o label para esquerda e o nível para direita na mesma linha.

**Atenção:** O `<View style={styles.footer}>` usa `flexDirection: 'row'` (linha 550). O banner precisa de `width: '100%'` e `flexWrap` no container pai para não quebrar o layout. Alterar o estilo do footer para suportar coluna:

```typescript
// Antes (linha 550):
footer: { padding: 20, paddingBottom: 36, borderTopWidth: 1, flexDirection: 'row', gap: 12 },

// Depois:
footer: { padding: 20, paddingBottom: 36, borderTopWidth: 1, flexDirection: 'column', gap: 0 },
```

E adicionar um `<View style={{ flexDirection: 'row', gap: 12 }}>` envolvendo os botões VOLTAR e PRÓXIMA/FINALIZAR existentes para manter o layout horizontal deles.
