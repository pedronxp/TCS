## Goal

Após a vistoria, o relatório PDF deve mostrar (1) o município correto da vistoria (não da matrix do agente) e (2) a foto capturada durante o formulário.

## Root Causes

### Bug municipio
- `wizard.tsx:372` usa `profile?.municipio || params.municipio` — prioridade errada, usa cidade do agente primeiro
- `resultado.tsx:123,137` no fallback usa `municipio: profile?.municipio` — ignora municipio real

### Bug foto
- `ReportDraft` não tem campo `foto_url`
- `resultado.tsx` SELECT do Supabase não inclui `foto_url`; `normalizar()` não mapeia; `buildDados()` não passa
- `relatorio.tsx` `exportarPDF()` não passa `foto_url` para `buildLaudoHtml()`

## Tasks

### Task 1 — wizard.tsx: corrigir prioridade do municipio
**File**: `app/(panel)/inspecoes/wizard.tsx:372`

Trocar:
```ts
municipio: profile?.municipio || params.municipio || '',
```
Por:
```ts
municipio: params.municipio || profile?.municipio || '',
```

### Task 2 — resultado.tsx: corrigir fallback municipio
**File**: `app/(panel)/inspecoes/resultado.tsx:123,137`

Nas duas ocorrências do fallback de params, trocar:
```ts
municipio: profile?.municipio,
```
Por:
```ts
municipio: (params as any)?.municipio || profile?.municipio,
```

### Task 3 — resultado.tsx: adicionar foto_url no SELECT + normalizar + buildDados
**File**: `app/(panel)/inspecoes/resultado.tsx`

a) SELECT Supabase (linha ~93): adicionar `foto_url` aos campos
b) `normalizar()`: adicionar `foto_url: v.foto_url ?? v.fotoUrl ?? null`
c) `buildDados()`: adicionar `foto_url: vistoria?.foto_url ?? null`

### Task 4 — ReportContext.tsx: adicionar foto_url no ReportDraft
**File**: `context/ReportContext.tsx`

Adicionar campo `foto_url?: string | null` em `ReportDraft`.

### Task 5 — resultado.tsx: passar foto_url no initReport
**File**: `app/(panel)/inspecoes/resultado.tsx`

Em `populateReport()`, adicionar `foto_url: v.foto_url ?? null` no objeto passado para `initReport()`.

### Task 6 — relatorio.tsx: passar foto_url no exportarPDF
**File**: `app/(panel)/inspecoes/relatorio.tsx`

Em `exportarPDF()`, adicionar `foto_url: draft.foto_url ?? null` no objeto `dados`.
