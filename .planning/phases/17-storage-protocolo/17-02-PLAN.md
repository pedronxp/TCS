## Goal

Quando o agente captura/seleciona uma foto durante a vistoria, o app faz upload imediato para o bucket `fotos/` do Supabase Storage e salva a URL pública em `fotoUrl` (SQLite) e `fotoUrl` (Supabase). Offline: mantém URI local, sincroniza quando online.

## Approach

- Bucket `fotos/` no Supabase Storage — política pública de leitura, autenticado para escrita
- Path: `fotos/{municipio}/{vistoria_id}.jpg`
- `supabase.storage.from('fotos').upload(path, file)`
- Atualizar `vistorias` com URL após upload bem-sucedido

## Tasks

### Task 1 — Criar bucket fotos no Supabase Storage

Via MCP Supabase execute_sql — a criação de buckets é via API, usar SQL do storage schema:

```sql
INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
VALUES (
  'fotos',
  'fotos',
  true,
  5242880, -- 5MB
  ARRAY['image/jpeg','image/jpg','image/png','image/webp']
)
ON CONFLICT (id) DO NOTHING;

-- Política: qualquer autenticado pode fazer upload
CREATE POLICY "autenticado_upload_fotos" ON storage.objects
  FOR INSERT WITH CHECK (
    bucket_id = 'fotos' AND auth.role() = 'authenticated'
  );

-- Política: leitura pública
CREATE POLICY "leitura_publica_fotos" ON storage.objects
  FOR SELECT USING (bucket_id = 'fotos');
```

### Task 2 — utils/storageUtils.ts (novo arquivo)

```ts
import { supabase } from '../services/supabaseClient';
import * as FileSystem from 'expo-file-system';
import { decode } from 'base64-arraybuffer';

export async function uploadFoto(
  localUri: string,
  vistoriaId: string,
  municipio: string
): Promise<string | null> {
  try {
    const base64 = await FileSystem.readAsStringAsync(localUri, {
      encoding: FileSystem.EncodingType.Base64,
    });
    const arrayBuffer = decode(base64);
    const path = `fotos/${municipio}/${vistoriaId}.jpg`;

    const { error } = await supabase.storage
      .from('fotos')
      .upload(path, arrayBuffer, {
        contentType: 'image/jpeg',
        upsert: true,
      });

    if (error) return null;

    const { data } = supabase.storage.from('fotos').getPublicUrl(path);
    return data.publicUrl;
  } catch {
    return null;
  }
}
```

### Task 3 — wizard.tsx: upload da foto após captura

No momento em que `fotoUri` é definido (após `ImagePicker` ou câmera), se online:
```ts
import { uploadFoto } from '../../../utils/storageUtils';

// Após definir fotoUri:
if (isConnected && fotoUri && vistoriaId) {
  const url = await uploadFoto(fotoUri, vistoriaId, municipio);
  if (url) {
    setFotoUrl(url); // estado local
    // Atualizar SQLite com URL do Storage
    await db.runAsync('UPDATE vistorias SET fotoUrl = ? WHERE id = ?', [url, vistoriaId]);
  }
}
```
