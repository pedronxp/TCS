## Goal

Após gerar o PDF (laudo ou relatório), fazer upload para bucket `laudos/` do Supabase Storage, salvar `laudo_url` e `laudo_gerado_em` em `vistorias`. Exibir botão "Regenerar Laudo" quando `laudo_gerado_em` > 7 dias ou `laudo_url` = null.

## Approach

- Bucket `laudos/` — leitura restrita a autenticados do mesmo município
- Path: `laudos/{municipio}/{vistoria_id}.pdf`
- Após `Print.printToFileAsync()`, ler o arquivo como base64 e fazer upload
- Salvar URL em `vistorias` (Supabase + SQLite)
- Lifecycle: não há lifecycle policy automática no Supabase Free — implementar lógica no app (verificar `laudo_gerado_em` + 7 dias)

### Task 1 — Criar bucket laudos no Supabase Storage

```sql
INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
VALUES (
  'laudos',
  'laudos',
  false,
  10485760, -- 10MB
  ARRAY['application/pdf']
)
ON CONFLICT (id) DO NOTHING;

-- Apenas autenticados podem ler laudos do próprio município
CREATE POLICY "autenticado_le_laudos" ON storage.objects
  FOR SELECT USING (
    bucket_id = 'laudos' AND auth.role() = 'authenticated'
  );

-- Apenas autenticados podem fazer upload
CREATE POLICY "autenticado_upload_laudos" ON storage.objects
  FOR INSERT WITH CHECK (
    bucket_id = 'laudos' AND auth.role() = 'authenticated'
  );

-- Pode sobrescrever (upsert para regenerar)
CREATE POLICY "autenticado_atualiza_laudos" ON storage.objects
  FOR UPDATE USING (
    bucket_id = 'laudos' AND auth.role() = 'authenticated'
  );
```

### Task 2 — utils/storageUtils.ts: função uploadLaudo

Adicionar ao arquivo existente:

```ts
export async function uploadLaudo(
  localUri: string,
  vistoriaId: string,
  municipio: string
): Promise<string | null> {
  try {
    const base64 = await FileSystem.readAsStringAsync(localUri, {
      encoding: FileSystem.EncodingType.Base64,
    });
    const arrayBuffer = decode(base64);
    const path = `laudos/${municipio}/${vistoriaId}.pdf`;

    const { error } = await supabase.storage
      .from('laudos')
      .upload(path, arrayBuffer, {
        contentType: 'application/pdf',
        upsert: true,
      });

    if (error) return null;

    // URL signed com 7 dias de validade
    const { data } = await supabase.storage
      .from('laudos')
      .createSignedUrl(path, 60 * 60 * 24 * 7);

    return data?.signedUrl ?? null;
  } catch {
    return null;
  }
}
```

```ts
import { uploadLaudo } from '../../../utils/storageUtils';

// Após gerar PDF:
if (isConnected && vistoria?.id) {
  const laudoUrl = await uploadLaudo(uri, vistoria.id, municipio);
  if (laudoUrl) {
    // Salvar no Supabase
    await supabase
      .from('vistorias')
      .update({ laudo_url: laudoUrl, laudo_gerado_em: new Date().toISOString() })
      .eq('id', vistoria.id);
    // Salvar no SQLite
    await db.runAsync(
      'UPDATE vistorias SET laudo_url = ?, laudo_gerado_em = ? WHERE id = ?',
      [laudoUrl, new Date().toISOString(), vistoria.id]
    );
  }
}
```

### Task 4 — resultado.tsx: botão "Regenerar Laudo"

Adicionar lógica para verificar expiração:

```ts
const laudoExpirado = useMemo(() => {
  if (!vistoria?.laudo_gerado_em) return false;
  const geradoEm = new Date(vistoria.laudo_gerado_em);
  const diasPassados = (Date.now() - geradoEm.getTime()) / (1000 * 60 * 60 * 24);
  return diasPassados >= 7;
}, [vistoria?.laudo_gerado_em]);

// No JSX — mostrar botão "Regenerar" se expirado, "Baixar Laudo" se válido
{laudoExpirado ? (

  <TouchableOpacity onPress={() => Linking.openURL(vistoria.laudo_url!)}>
    <Feather name="download" /> <Text>Baixar Laudo</Text>
  </TouchableOpacity>
) : null}
```
