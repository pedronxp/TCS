## Goal

No dia 6 após geração do laudo, o agente que criou a vistoria recebe 1 notificação agrupada (digest) informando quantos laudos expiram amanhã. Máximo 1 push por dia por agente.

## Approach

- Verificação feita no app ao abrir (`AppState` foreground) e via agendamento local (`expo-notifications` scheduled)
- Sem servidor — tudo client-side: consulta SQLite/Supabase por laudos com `laudo_gerado_em` entre 6 e 7 dias atrás
- Agendar notificação para 09:00 do dia seguinte se ainda não agendada hoje
- Usar `Notifications.scheduleNotificationAsync()` com `trigger: { hour: 9, minute: 0, repeats: false }`

## Tasks

### Task 1 — utils/laudoExpiracaoNotif.ts (novo arquivo)

```ts
import * as Notifications from 'expo-notifications';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { getDb } from './database';

const LAST_DIGEST_KEY = 'last_laudo_digest_date';

export async function verificarLaudosExpirando(): Promise<void> {
  // Verificar se já rodou hoje
  const hoje = new Date().toISOString().split('T')[0];
  const ultimoDigest = await AsyncStorage.getItem(LAST_DIGEST_KEY);
  if (ultimoDigest === hoje) return;

  const db = await getDb();
  const agora = Date.now();
  const dia6 = agora - 6 * 24 * 60 * 60 * 1000;
  const dia7 = agora - 7 * 24 * 60 * 60 * 1000;

  // Buscar laudos gerados há entre 6 e 7 dias
  const laudos = await db.getAllAsync<{ id: string }>(
    `SELECT id FROM vistorias
     WHERE laudo_gerado_em IS NOT NULL
       AND CAST(strftime('%s', laudo_gerado_em) AS INTEGER) * 1000 BETWEEN ? AND ?`,
    [dia7, dia6]
  );

  if (laudos.length === 0) return;

  const count = laudos.length;
  const titulo = count === 1
    ? 'Laudo expira amanhã'
    : `${count} laudos expiram amanhã`;
  const corpo = count === 1
    ? 'Abra o app para regenerar antes que expire.'
    : 'Abra o app para regenerar os laudos antes que expirem.';

  await Notifications.scheduleNotificationAsync({
    content: {
      title: titulo,
      body: corpo,
      data: { tipo: 'laudo_expiracao' },
    },
    trigger: {
      hour: 9,
      minute: 0,
      repeats: false,
    } as any,
  });

  await AsyncStorage.setItem(LAST_DIGEST_KEY, hoje);
}
```

### Task 2 — context/AuthContext.tsx ou app/_layout.tsx: chamar verificarLaudosExpirando

No `useEffect` de foreground do app (quando autenticado):

```ts
import { verificarLaudosExpirando } from '../utils/laudoExpiracaoNotif';

// Após login ou ao voltar ao foreground:
useEffect(() => {
  if (user) {
    verificarLaudosExpirando().catch(() => {});
  }
}, [user]);
```
