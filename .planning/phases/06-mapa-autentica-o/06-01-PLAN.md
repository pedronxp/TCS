<objective>
Corrige os dois problemas restantes que causam tela branca no mapa Leaflet/WebView.

Problema 1 (MAPA-01): O `initMap()` no HTML tenta apenas UMA vez após 100ms. Em Android físico, o layout do WebView pode demorar 300–500ms para ter dimensões não-zero. Se a primeira tentativa encontra `offsetWidth === 0`, ela agenda outro retry recursivo — mas o design atual tem um loop de retentativa que pode parar prematuramente. Solução: implementar loop com até 15 retentativas (1500ms total) antes de chamar `showError()`.

Problema 2 (MAPA-02): Quando um script CDN falha (`s.onerror`), o código chama `showError()` mas NÃO envia mensagem ao React Native. O estado de loading do React nunca é resolvido, então a WebView fica congelada sem o overlay nativo de erro. Solução: após `showError()`, chamar `window.ReactNativeWebView.postMessage(JSON.stringify({type:'loadError',msg:'...'}))`.

Problema 3 (MAPA-01): O `invalidateSize` atual usa `setTimeout(300ms)` DENTRO do HTML — isso é não-confiável porque o timer começa quando o HTML executa, não quando o layout nativo finaliza. Solução: adicionar `onLoadEnd` na WebView que chama `injectJavaScript` com `map.invalidateSize` após 500ms do onLoadEnd nativo (que dispara APÓS o layout nativo).

Purpose: Mapa funcional é bloqueador para agentes em campo.
Output: `app/(panel)/mapas.tsx` modificado com WebView confiável em Android + iOS.
</objective>
