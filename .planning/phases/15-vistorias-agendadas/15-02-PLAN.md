## Goal

Supervisor, Admin e Master_admin podem criar agendamentos. O ícone de calendário fica no header de todas as telas principais (ao lado do ícone de perfil).

## Tasks

### Task 1 — Ícone de agendamentos no header

**Files**: `app/(panel)/dashboard.tsx`, `app/(panel)/admin/index.tsx`, `app/(panel)/supervisor/index.tsx`, `app/(panel)/master/index.tsx`

Adicionar botão de calendário no header, ao lado do ícone de perfil existente:
```tsx
<TouchableOpacity
  style={[styles.headerIconBtn, { backgroundColor: theme.iconBackground, borderColor: theme.border }]}
  onPress={() => router.push('/(panel)/agendamentos')}
>
  <Feather name="calendar" size={20} color={theme.textSecondary} />
</TouchableOpacity>
```

O botão aparece para TODOS os roles (agentes verão só a lista, admins/supervisors verão o botão de criar).

### Task 2 — Tela de lista de agendamentos (app/(panel)/agendamentos/index.tsx)

Nova tela que:
- Busca agendamentos do Supabase (fallback SQLite)
- Filtra por município do perfil (exceto master_admin vê todos)
- Exibe lista de cards com: título, data/hora formatada, endereço, status badge, agente atribuído
- **Agente**: vê somente agendamentos atribuídos a ele (agente_uid = profile.uid) ou sem atribuição
- **Supervisor/Admin/Master**: vê todos do município + botão FAB "+" para criar

Status badge:
- `pendente` → cinza/azul
- `concluido` → verde
- `cancelado` → vermelho

### Task 3 — Modal de criação (dentro da tela de agendamentos)

Modal disponível apenas para roles `supervisor`, `admin`, `master_admin`:

Campos:
- Título* (ex: "Vistoria Rua das Flores, 42")
- Endereço (texto livre)
- Data e hora* (DateTimePicker)
- Agente atribuído (lista dropdown com agentes do município — busca `users` onde `role='agent'` e `municipio=profile.municipio`)
- Observações (multiline)

Ao salvar:
1. Gera UUID local
2. `insertAgendamento()` no SQLite
3. `supabase.from('agendamentos').upsert()` se online
4. Fecha modal e atualiza lista

### Task 4 — app/(panel)/agendamentos/_layout.tsx

Layout simples para a rota de agendamentos.

## Navigation
