## Goal

A partir de qualquer vistoria com coordenadas, o usuário pode abrir a navegação nativa (Google Maps no Android, Apple Maps no iOS) com a rota traçada da posição atual até a vistoria.

## Approach

Usar `Linking.openURL()` com URLs universais de mapas:
- **Android**: `google.navigation:q=LAT,LNG&mode=d` (abre Google Maps direto em modo navegação)
- **iOS**: `maps://maps.apple.com/?daddr=LAT,LNG&dirflg=d` (Apple Maps com direções)

GPS atual via `expo-location` (já instalado) — `Location.getCurrentPositionAsync()`.

Se o usuário não tiver Google Maps instalado no Android, fallback para `https://www.google.com/maps/dir/?api=1&destination=LAT,LNG`.

## Tasks

### Task 1 — utils/routingUtils.ts (novo arquivo)

```ts
import { Linking, Platform } from 'react-native';
import * as Location from 'expo-location';

export async function tracarRota(lat: number, lng: number): Promise<void> {
  const { status } = await Location.requestForegroundPermissionsAsync();
  let origem = '';

  if (status === 'granted') {
    const pos = await Location.getCurrentPositionAsync({ accuracy: Location.Accuracy.Balanced });
    origem = `${pos.coords.latitude},${pos.coords.longitude}`;
  }

  let url: string;
  if (Platform.OS === 'ios') {
    url = origem
      ? `maps://maps.apple.com/?saddr=${origem}&daddr=${lat},${lng}&dirflg=d`
      : `maps://maps.apple.com/?daddr=${lat},${lng}&dirflg=d`;
  } else {
    url = `google.navigation:q=${lat},${lng}&mode=d`;
  }

  const canOpen = await Linking.canOpenURL(url);
  if (canOpen) {
    await Linking.openURL(url);
  } else {
    // Fallback para Google Maps web
    const fallback = `https://www.google.com/maps/dir/?api=1&destination=${lat},${lng}`;
    await Linking.openURL(fallback);
  }
}
```
