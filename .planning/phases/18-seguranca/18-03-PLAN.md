## Goal

Reforçar os tokens de convite: armazenar hash do token (não texto plano), vincular o email do destinatário no momento da criação, garantir expiração máxima de 72h e invalidar imediatamente após uso.

## Approach

- `invite_tokens` já tem `expiraEm`, `usado`, `usadoPorIp` — estender com `email_destinatario` e `token_hash`
- Hash SHA-256 do token antes de salvar no banco (token original vai apenas no link/QR)
- Verificação no app: comparar hash
- Expiração padrão: 72h (não configurável pelo usuário)

### Task 2 — utils/tokenUtils.ts (novo arquivo)

```ts
import * as Crypto from 'expo-crypto';

export async function hashToken(token: string): Promise<string> {
  return await Crypto.digestStringAsync(
    Crypto.CryptoDigestAlgorithm.SHA256,
    token
  );
}

export function gerarTokenSeguro(): string {
  // 32 bytes aleatórios → hex string de 64 chars
  const array = new Uint8Array(32);
  crypto.getRandomValues(array);
  return Array.from(array).map(b => b.toString(16).padStart(2, '0')).join('');
}

export function calcularExpiracao72h(): string {
  const expira = new Date();
  expira.setHours(expira.getHours() + 72);
  return expira.toISOString();
}
```

### Task 3 — admin/gerar-token.tsx: usar token seguro com hash

Ao criar token:
```ts
import { gerarTokenSeguro, hashToken, calcularExpiracao72h } from '../../../utils/tokenUtils';

const token = gerarTokenSeguro();
const hash = await hashToken(token);
const expiracao = calcularExpiracao72h();

await supabase.from('invite_tokens').insert({
  codigo: token, // token original (só mostrado uma vez)
  token_hash: hash,
  municipio: formData.municipio,
  role: formData.role,
  email_destinatario: formData.email || null,
  expiraEm: expiracao,
  usado: false,
});
```

### Task 4 — app/(auth)/register.tsx: verificar hash e email

Ao validar token no cadastro:
```ts
import { hashToken } from '../../utils/tokenUtils';

// Verificar por hash em vez de texto plano
const hash = await hashToken(tokenInput);
const { data: tokenData } = await supabase
  .from('invite_tokens')
  .select('*')
  .eq('token_hash', hash)
  .eq('usado', false)
  .gt('expiraEm', new Date().toISOString())
  .single();

// Se email_destinatario definido, verificar que o email do cadastro bate
if (tokenData?.email_destinatario &&
    tokenData.email_destinatario.toLowerCase() !== email.toLowerCase()) {
  Alert.alert('Token inválido', 'Este token foi gerado para outro email.');
  return;
}

// Marcar usado imediatamente
await supabase.from('invite_tokens')
  .update({ usado: true, usado_em: new Date().toISOString() })
  .eq('token_hash', hash);
```
