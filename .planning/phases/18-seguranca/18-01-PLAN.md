## Goal

Auditar todas as tabelas do Supabase que têm RLS ativado, identificar gaps (tabelas sem políticas, políticas permissivas demais, ausência de política de DELETE) e corrigir via migrations.

## Approach

Consultar `pg_policies` e `pg_tables` via MCP Supabase para mapear estado atual. Corrigir gaps encontrados.

## Tasks

### Task 1 — Listar todas as tabelas e suas políticas atuais

Executar SQL:
```sql
SELECT
  t.tablename,
  t.rowsecurity,
  p.policyname,
  p.cmd,
  p.qual,
  p.with_check
FROM pg_tables t
LEFT JOIN pg_policies p ON t.tablename = p.tablename
WHERE t.schemaname = 'public'
ORDER BY t.tablename, p.policyname;
```

### Task 2 — Identificar e corrigir gaps

Gaps comuns a verificar:
1. Tabelas sem nenhuma política (RLS ativo mas sem regras = ninguém acessa)
2. `FOR ALL` sem restrição de role (qualquer autenticado pode tudo)
3. Ausência de política para `DELETE` em tabelas sensíveis
4. `vistorias`: agente só deve poder ver/editar as próprias vistorias
5. `users`: agente não deve poder ver dados de outros agentes
6. `audit_logs`: somente leitura para admin+
7. `contadores_protocolo`: somente service_role (já feito, confirmar)

### Task 3 — Aplicar correções

```sql
-- vistorias: agente vê só as próprias; admin/supervisor vê o município
DROP POLICY IF EXISTS "agente_ve_proprias_vistorias" ON vistorias;
CREATE POLICY "agente_ve_proprias_vistorias" ON vistorias
  FOR SELECT USING (
    "agenteUid" = auth.uid()
    OR (SELECT role FROM users WHERE uid = auth.uid()) IN ('admin', 'supervisor', 'master_admin')
  );

DROP POLICY IF EXISTS "agente_insere_propria_vistoria" ON vistorias;
CREATE POLICY "agente_insere_propria_vistoria" ON vistorias
  FOR INSERT WITH CHECK (
    "agenteUid" = auth.uid()
  );

DROP POLICY IF EXISTS "agente_atualiza_propria_vistoria" ON vistorias;
CREATE POLICY "agente_atualiza_propria_vistoria" ON vistorias
  FOR UPDATE USING (
    "agenteUid" = auth.uid()
    OR (SELECT role FROM users WHERE uid = auth.uid()) IN ('admin', 'supervisor', 'master_admin')
  );

-- Nenhum usuário comum pode deletar vistorias (somente master_admin)
DROP POLICY IF EXISTS "master_admin_deleta_vistoria" ON vistorias;
CREATE POLICY "master_admin_deleta_vistoria" ON vistorias
  FOR DELETE USING (
    (SELECT role FROM users WHERE uid = auth.uid()) = 'master_admin'
  );

-- users: agente vê apenas o próprio perfil; admin/supervisor vê do município
DROP POLICY IF EXISTS "usuario_ve_proprio_perfil" ON users;
CREATE POLICY "usuario_ve_proprio_perfil" ON users
  FOR SELECT USING (
    uid = auth.uid()
    OR (SELECT role FROM users WHERE uid = auth.uid()) IN ('admin', 'supervisor', 'master_admin')
  );

-- audit_logs: somente leitura para admin+, insert para qualquer autenticado
DROP POLICY IF EXISTS "admins_le_audit_logs" ON audit_logs;
CREATE POLICY "admins_le_audit_logs" ON audit_logs
  FOR SELECT USING (
    (SELECT role FROM users WHERE uid = auth.uid()) IN ('admin', 'supervisor', 'master_admin')
  );

DROP POLICY IF EXISTS "autenticado_insere_audit_log" ON audit_logs;
CREATE POLICY "autenticado_insere_audit_log" ON audit_logs
  FOR INSERT WITH CHECK (auth.role() = 'authenticated');
```
